# Analytical-panel data dictionary

| Variable | Definition | Unit |
| --- | --- | --- |
| `country` | Harmonized country name | text |
| `year` | Observation year | year |
| `iso_code` | ISO 3166-1 alpha-3 country code | text |
| `renewables_electricity` | Renewable electricity generation | TWh |
| `fossil_electricity` | Electricity generation from coal, oil, and gas | TWh |
| `electricity_generation` | Total electricity generation | TWh |
| `electricity_demand` | Electricity demand | TWh |
| `fossil_share_elec` | Fossil share of electricity generation | percent |
| `net_elec_imports_share_demand` | Net electricity imports as a share of demand | percent |
| `wind_electricity` | Wind electricity generation | TWh |
| `solar_electricity` | Solar electricity generation | TWh |
| `nuclear_electricity` | Nuclear electricity generation | TWh |
| `country_source` | Country name in the frozen source | text |
| `renewables_change_twh` | Annual change in renewable generation | TWh |
| `fossil_change_twh` | Annual change in fossil generation | TWh |
| `prior_generation_twh` | Previous year's total electricity generation | TWh |
| `electricity_demand_growth_pct` | Annual percentage change in electricity demand | percent |
| `wind_solar_share_elec` | Wind plus solar generation divided by total generation | percent |
| `nuclear_share_elec` | Nuclear generation divided by total generation | percent |
